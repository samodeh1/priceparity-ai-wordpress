# PriceParity AI Widget for WordPress

Shows purchasing-power prices from [PriceParity AI](https://www.priceparityai.com) on
WordPress and WooCommerce sites. WooCommerce product prices are marked automatically; on
regular pages, use the shortcode `[priceparity_price price="100"]`.

The plugin changes the displayed price only. It does not change cart or checkout totals.

## Install

Download `priceparity-ai.zip` from the
[latest release](https://github.com/samodeh1/priceparity-ai-wordpress/releases/latest),
then in WordPress open **Plugins > Add New > Upload Plugin** and upload it.
